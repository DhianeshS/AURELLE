# AURELLE

> Make space for your best self.

An elegant, minimal personal productivity platform built with Next.js, TypeScript, and Tailwind CSS. Aurelle helps you cultivate intentional daily habits, manage deep work tasks, track strategic goals, and review progress through thoughtful analytics.

---

## ✨ Features

- **Daily Habits Tracking**: Build streak consistency with flexible daily check-ins and progress metrics.
- **Deep Work Tasks**: Organize tasks with priorities, status tracking, time blocking, and labels.
- **Strategic Goals & Milestones**: Connect long-term vision with actionable steps.
- **Analytics & Reflections**: Visualize your completion rates, trends, and weekly cadence.
- **Calendar View**: High-level scheduling and timeline visibility.
- **Local-First & Offline-Ready**: Fast, responsive, and keeps data in sync locally.

---

## 🛠 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) 14 (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Charts**: [Recharts](https://recharts.org/)
- **Utilities**: `date-fns`, `clsx`, `tailwind-merge`, `zod`

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or yarn or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/DhianeshS/AURELLE.git

# Navigate to the project directory
cd AURELLE

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

---

## 📦 Scripts

- `npm run dev` - Start development server
- `npm run build` - Build production bundle
- `npm run start` - Start production server
- `npm run lint` - Run ESLint checks
